## 📖 About this Repository

Artificial Intelligence is changing how software is built, but it also introduces entirely new attack surfaces.

This repository is a practical knowledge base focused on securing modern AI applications from a Security Engineer and Security Architect perspective.

Unlike traditional AI repositories that focus only on model development, this repository focuses on **how to secure AI systems in production**.

Topics include:

- AI Fundamentals
- Large Language Models (LLMs)
- AI Agents
- Model Context Protocol (MCP)
- Prompt Injection
- Retrieval Augmented Generation (RAG)
- Secure AI APIs
- Kubernetes Security
- Cloud Security
- AI DevSecOps
- AI Governance
- OWASP LLM Top 10
- Hands-on Security Labs
- Interview Preparation
